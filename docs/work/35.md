Oracle back ends for the suite's region/sequence format (the DOS one is `rea-suite dosbox`):

- **GDB RSP**: Dolphin (`-C Dolphin.General.GDBPort=N`, headless with `dolphin-emu-nogui -p headless`) and the other emulators with a GDB stub. docs/GAMECUBE-WII.md step 4.
- **PPSSPP's WebSocket API** (no GDB stub in v1.20.4): `ws://127.0.0.1:<port>/debugger`, subprotocol `debugger.ppsspp.org`. docs/PSP.md step 5.

Trap for the PPSSPP one: while its web server runs, PPSSPP reports the local IP and port to report.ppsspp.org every nine minutes (`RegisterServer` in `Core/WebServer.cpp`), and no setting turns that off in v1.20.4. The back end keeps `RemoteDebuggerOnStartup` off unless the user turns it on, and says so.
