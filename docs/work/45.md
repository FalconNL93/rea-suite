From the new cod4 port (Call of Duty 4: Modern Warfare, IW3, PC 1.7; 2026-11-15): GAME-ARCHIVES.md has nothing for IW engines' fastfiles. Wanted: `rea-suite` lists and extracts a PC IW3 .ff: the header (version, PC/console), the zlib stream inflated, the zone (its sizes and blocks) and the xasset list (types and names), extracting raw files, string tables, localized strings and images first. Later IW versions (IW4/IW5, signed or encrypted fastfiles, console variants: cod3 is IW3-era on Xbox 360) as reserved extension points. Reference to check, license first: OpenAssetTools (its license decides whether it is wrapped as a tool or only read as documentation); cod4's research agent is checking it. .iwd is plain zip (no gap). Tests on a synthetic .ff and, opt-in, the owner's game files.
