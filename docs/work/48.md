Generate a Win32 import table for winrt's census mode (winrt, 2026-11-15; for cod4's census rerun, winrt#30). Census mode returns from a missing method by its argument count; to return from a missing import as well, it needs each import's argument count and calling convention. winrt reads the table at run time (`<GAME>_CENSUS_IMPORTS=<file>`); rea-suite owns its generation.

File: `common/rea_suite/data/census/win32-imports.json` (rea-census-slots/1, `"kind": "imports"`, functions keyed `module!Name`), generated by census_slots.py:
- args and conv from MinGW-w64's i686 import libraries (`_Name@N` is stdcall with N/4 arguments; undecorated is cdecl);
- ordinals from Windows' own 32-bit DLLs (SysWOW64): each named export also as `module!#n`, for games that import by ordinal (wsock32 #101, dsound #6);
- mss32.dll (Miles) from a game's copy, whose exports are decorated (`_AIL_open_digital_driver@16`);
- returns_float from MinGW's headers where a function returns FLOAT or double.
Modules: kernel32, user32, gdi32, advapi32, winmm, wsock32, ws2_32, ole32, oleaut32, shell32, version, imm32, comctl32, comdlg32, d3d9, d3dx9_24..43, dinput, dinput8, dsound, ddraw, msvcrt, opengl32, glu32, xinput, wininet, iphlpapi, mss32.
