Ghidra has no SPU language, so `rea-suite ps3 analyze` lists embedded SPU images but does not import them. GhidraSPU (aerosoul94, Apache-2.0) is a candidate: its SLEIGH compiles with Ghidra 12.1.4, but its Java relocation handler targets Ghidra 9.2. ps3-cell-re-tools' `spu-sleigh` (GPL-2.0) builds a lane-correct model on top of it. Wanted: an SPU language that builds with the pinned Ghidra, and `analyze` importing each SPU image found by the census. Filed from the PS3 route (2026-11-13).
