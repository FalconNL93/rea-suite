Every import a run reached, not only those named (the harvest of 2026-11-15, item 1; the orchestrator). An import in the IAT is no proof that the game calls it. A port needs the list of imports and functions a real run reached, to order its gap and to prove a service is never used. alan-wakeii built this as `tools/native_probe.py` and `native_probe.js`: Frida, a fresh profile, disk writes guarded. The 2026-11-13 gap analysis lists it as item 11.

Today `common/frida/observer.js` counts calls through the IAT slots a caller names one by one. Wanted: a mode that hooks every IAT slot of the main image (and, optionally, of the DLLs the game ships). It should report per import the calls and the first caller, as JSON lines. A drcov output would serve coverage tools too. Its runtime half lines up with the census (docs/census.md): it could write a rea-census/1 `runtime` document for Windows itself, beside winrt's census mode.

Who uses it: every Win32 port (AWR, Lost, Rogue Spear, Max Payne, CoD1). Size: medium.
