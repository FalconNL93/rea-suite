`rea-suite pe refs` that also finds an address stored in data (the harvest of 2026-11-15, item 2; the orchestrator). alan-wake-rm proved a function dead (`docs/research/2026-11-12-havok-vdb.md`): it searched the whole file for the function's literal address. A control search on a known function showed the method finds what exists, so the empty result meant absence.

`scan.refs` reads code sections only, and `pe rtti` covers vtables. Wanted: `pe refs <exe> <address> --data`, which also lists pointer-sized hits in data sections (section, offset, the containing vtable or table where known), and `--control <address>`, which runs the same search on a known address and says whether it was found, so an empty answer for the target is evidence.

Who uses it: dead-code and no-call-home proofs (checklist 29) in every PE port, function-pointer tables and callbacks. Size: small.
